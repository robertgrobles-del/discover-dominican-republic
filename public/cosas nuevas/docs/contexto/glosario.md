# glosario.md — Términos del portal

> Cada término significa una sola cosa y se traduce siempre igual.
> Si una pantalla usa otra palabra para lo mismo, se cambia la pantalla.
> Las traducciones son una base; conviene que las revise un hablante nativo de cada idioma.

---

## Términos de negocio

| Término | Qué significa | No confundir con |
|---|---|---|
| **Ficha** | Página de un establecimiento o lugar en el portal | "Perfil" (es de usuarios) |
| **Ficha Básica** | Plan gratuito de ficha | — |
| **Premium** | Plan pagado de ficha, con WhatsApp, galería completa y contactos | Paquete Premium del pitch de hoteles |
| **Destacado** | Plan o posición pagada que sube la ficha en su destino y categoría | "Recomendado" (editorial, no se paga) |
| **Patrocinado** | Contenido o anuncio pagado, siempre etiquetado | "Destacado" |
| **Paquete** | Oferta comercial para hoteles o restaurantes (Esencial a Partner) | "Plan" |
| **Aliado** | Negocio o agencia en el programa de alianzas | "Cliente" (paga un plan) |
| **Contacto** | Una persona que escribió, llamó o pidió cómo llegar desde la ficha | "Visita" o "lead" (no usar "lead" en pantalla) |
| **Reserva** | Compra o solicitud confirmada de un servicio | "Contacto" |
| **Verificado** | Negocio cuya licencia o identidad se comprobó | "Destacado" |
| **Operador** | Empresa que vende excursiones o servicios reservables | "Agencia" |
| **Agencia** | Agencia de viajes (receptiva, emisora o mayorista) | "Operador" |
| **Guía** | Persona con licencia que acompaña recorridos | "Guía" de contenido (artículo) |
| **Piloto** | Programa gratuito de 90 días para restaurantes | "Prueba gratuita" del plan Premium |

## Términos del viajero

| Término | Qué significa |
|---|---|
| **Pasaporte digital** | Registro de sellos por lugares visitados |
| **Sello** | Registro verificado de una visita |
| **Misión** | Reto con recompensa |
| **Monedas** | Moneda del juego, canjeable por premios |
| **XP** | Puntos de experiencia que suben el nivel |
| **Mi viaje** | Espacio del usuario con itinerario, favoritos y reservas |
| **Favoritos** | Lugares guardados |
